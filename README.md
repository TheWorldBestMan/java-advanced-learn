# Java 进阶 · 数据结构与算法 学习网站

一个**静态课程 + 可选本地 Java 运行**的学习站：14 大专题、34 个小节，每个小结都按
「概念 → 符号/方法速查 → 简单使用案例 → 运用场景 → 使用案例 → 易错点易忘点 → 题目」组织，复杂的专题（动态规划、图、回溯等）讲得更细。

## 怎么打开

**手机或电脑在线阅读：**[Java 进阶学习网站](https://theworldbestman.github.io/java-advanced-learn/)。GitHub Pages 提供课程、测验和步骤演示；Java 编译运行和公开测试需要下面的本地服务。进度和草稿按浏览器及网址分别保存，换设备前可导出备份并在新设备导入。

**Windows（推荐）**

双击 `启动学习网站.bat`。脚本会启动仅本机可访问的服务器（需已安装 Node.js）并自动打开浏览器。运行案例和公开测试还需要安装 JDK，并让 `javac`、`java` 可用；直接打开 `index.html` 可阅读课程、编辑代码和使用步骤演示。

更新后请先关闭旧的服务器窗口，再重新双击启动脚本，并在浏览器按 Ctrl+F5 刷新。

**手动方式**

- 直接双击 `index.html`（Chrome / Edge 都行）
- 或在目录里执行 `node server.js`，然后访问 http://localhost:8766/

**手机 / 平板**

在可信的家庭或个人网络中，双击 `启动手机访问.bat`，手机连**同一 WiFi**，打开窗口中打印的局域网地址。首次运行 Java 时输入窗口中的访问码；每次重启服务都会更换访问码。用完后关闭服务窗口。也可以在命令行运行 `node server.js --lan`。

运行器以电脑上启动服务的用户权限执行 Java，超时和内存限制不是安全沙箱。只运行自己信任的代码，不要把该服务或访问码提供给不可信的人，也不要将服务暴露到公网。

## 专题知识地图

首页和侧栏可进入 13 个独立专题，覆盖树、图、数组、链表、哈希与栈队列、双指针与区间、递归回溯、排序二分、动态规划、堆与贪心、字符串、位运算和动态区间结构。56 个知识分支分别整理题型识别、核心概念、步骤、例子、易错点、复杂度和对应练习入口，专题末尾提供自测。树和图附有 4 份完整 Java 程序；可复制到 IDE，或通过本地服务运行。

专题分支及题目名称可以在全站搜索中查找和收藏。题目链接跳转力扣，对方平台的完成状态不会自动同步回本站。专题是原有课程的知识地图，不会改变原章节链接、进度和草稿。

首页会根据上次打开的小节和完成情况显示“继续学习”。学习进度、编程练习代码、案例草稿与项目草稿保存在当前浏览器；首页“我的学习进度”提供导出和导入备份。换浏览器或设备前先导出 JSON 文件，在新浏览器中导入会覆盖该浏览器现有记录。手机目录可用菜单按钮打开，点遮罩、关闭按钮或按 Esc 收起。

“我的复习”集中列出测验错题、未通过的公开测试和搜索收藏；错题可以重做。课程练习会记录当前代码的公开测试结果，修改代码后提示重新测试。标记阅读、手动完成和通过公开测试是不同的记录，公开测试通过不代表所有情况都正确。搜索支持按学习状态和收藏筛选。存储失败时页面会提示，当前编辑内容可复制或从首页导出备份；多设备之间仍需手动导出、导入。

首页可按每周可用分钟数安排未完成的小节，沿现有课程顺序推荐，并在读完一章后提示测验；预计时间仅供安排阅读，练习所需时间因人而异。

## 新增的交互学习功能

- **128 个案例编辑器**：在“使用案例”中点击“编辑 / 运行代码”，修改 main 的输入或算法后直接运行；修改自动保存在当前浏览器，可复制当前代码或恢复原代码。
- **128 份案例方法取舍**：每个使用案例都对照另一种做法和当前做法的时间、额外空间，并解释何时值得选用；当前案例只是用于讲解而有更好方法时，会直接指出更优解及适用前提。空间默认不计输入和必须返回的结果，哈希复杂度按平均情况讨论。
- **30 种算法步骤演示**：覆盖全部 34 小节，支持上一步、下一步、进度拖动、自动播放、暂停和速度调整。可输入数据的演示提供输入格式说明；其余使用固定教学样例。
- **分步骤讲解**：34 份方法对照讲解，包括直接做法、优化方法、循环中应成立的条件、时间空间复杂度和易错点。代码显示行号，复杂案例配有 94 个专门编写的行级解释，其余案例展示关键注释说明。
- **185 组课程公开测试**：37 道编程练习各 5 组，覆盖普通输入与边界。测试直接调用题目方法，逐组展示输入、预期、实际结果、运行错误或超时。排列/子集按题目语义忽略答案列表顺序。

步骤演示展示给定算法的状态变化；在案例编辑器修改代码后，请点击“运行当前代码”查看实际 Java 输出。

## 搜索、解法对比与项目工坊

首页和左侧目录新增四个入口，顶部“搜索”按钮也可进入全站目录；在非编辑状态按 `/` 可快速打开搜索。

- **搜索与案例目录**：索引课程、128 个代码案例、编程练习、经典题目、面试问答、测验、场景题，以及新练习和项目。支持多个关键词同时匹配，并组合内容类型、章节、难度、算法筛选。可以一键只看代码案例；结果直接跳到具体内容，筛选条件保存在页面地址中。

## 学习建议

1. 按四阶段路线推进：01～04 数据与基本操作；05～07 递归、顺序与树；08～11 算法框架与状态；12～14 进阶专题与综合应用。
2. 每章说明放在当前位置的原因；每节说明为什么学、建议先学、后续具体如何复用，以及可以继续学习的标准。前后关联可点击跳转。
3. 每个小结：先看「概念」建立直觉 → 抄一遍「使用案例」→ 读「易错点」→ 做「题目」。
4. 先用“上一步 / 下一步”观察过程，再修改案例输入并运行；也可一键复制到 IDEA。
5. 每天 1~2 个专题、配 3~5 道题，一个月能系统过一遍常见面试算法。

## 关于运行代码

案例的“运行当前代码”和练习的“运行代码”编译并执行 main；“运行 5 组公开测试”另行调用解题方法，编译一次、分别运行测试。代码结构检查只提供写法提示，不代表结果正确。

本地执行设置了 15 秒编译等待、每组测试 5 秒运行等待、128 MB Java 堆上限和输出长度限制。全部测试均为公开练习用例，通过表示通过这些已列出的测试；本站不提供隐藏测试排名。运行服务用于个人学习代码，静态托管时课程和演示可用，Java 执行需要电脑本地服务。

位运算、差分与单调队列、字典树与 KMP、树状数组与线段树、带权图这五章的每个小节另配 4 道经典题目，共 40 个题目入口（37 道不同题目，部分题目在不同算法章节提供解法对照）。题目卡片显示力扣题号、难度、练习重点，并直接链接到对应题目页；可在全站搜索中按题号、题名、章节和难度查找。

## 学习路线与编号

章节与小节按先修关系、基础性和难度统一编排。排序由 `content/learning-path.js` 在课程数据加载后应用，首页、侧栏、小节标签、面包屑、搜索和正文中的章节引用同步更新。

- 第 2 章先哈希表、再栈与队列；第 3 章先前缀和、再双指针与窗口。
- 位运算提前到第 4 章，为子集表示与树状数组提供基础。
- 第 5 章递归分治先于第 6 章排序与二分；第 7 章树先 DFS、后 BFS。
- 第 8 章先差分扫描线、再单调队列；第 9 章堆与贪心、第 10 章图为后续综合算法准备工具。
- 第 11 章动态规划后，再进入文本检索、动态区间与带权图专题。涉及 DP 的早期挑战题明确提示完成 DP 后回访。
- 每个小节显示直接依赖它的后续小节及具体原因；沿先修链的覆盖数量根据路线计算，专题终点说明实际用途。
- 页面末尾的上一节/下一节遵循同一顺序；旧章节、小节与练习 ID 不变，原链接、学习进度、测验记录和草稿继续有效。源码文件名用于稳定标识内容来源，与展示章节号分开。

## 想加内容？

打开 `content/` 下任意章节文件，照着结构复制一节，改 `id`（全局唯一）和标题即可；
新章节需在 `index.html` 中引入，并在 `content/learning-path.js` 补齐顺序、先修关系和学习定位；保持每条先修关系均指向更早的小节。补充内容脚本放在学习路线脚本之前，刷新后首页与侧栏使用统一顺序。
新增“使用案例”时，也要在 `content/case-tradeoffs.js` 按章节/小节和案例顺序补齐替代方法、当前做法的时空成本及适用条件；若当前做法只是教学示例，应明确给出更适合实际使用的方法。

## 概念之后的入门层

每个小节在「运用场景」之前增加「常见符号 / 方法速查」和「简单使用案例」。位运算先演示按位与、或、异或、取反及有/无符号右移；递归先观察 3 的阶乘；树状数组先做一次更新和一次前缀查询。较复杂的题目仍放在后面的使用案例中。

34 份入门小程序使用独立标识，沿用案例编辑器与浏览器草稿保存。搜索增加「入门示例与符号速查」类型，可按方法名查找并直接定位。原 128 个场景案例、经典题目、解法对比和原来的学习记录继续保留。Java 实际运行仍使用本地启动服务。
